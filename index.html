Pattern reading

When you add a PDF, Claude reads it and turns it into row-by-row steps with techniques. This uses your own Anthropic API key, which is saved only on this device and sent only to Anthropic. Each pattern costs roughly a few cents to read.

Get a key at console.anthropic.com.

Backup

Your patterns, PDFs and projects are stored on this device only. Download a backup to keep a copy or to move everything to another phone or computer, then restore it there.
